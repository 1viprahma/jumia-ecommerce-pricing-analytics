# Jumia E-Commerce Pricing Analytics & Predictive Modeling

## Project Overview

Developed an end-to-end data science project using the CRISP-DM methodology to analyze and predict product prices from Jumia e-commerce data. The project combines web scraping, data preprocessing, exploratory data analysis, and machine learning techniques to uncover market trends and build an automated pricing prediction system.

## Dataset

* Web-scraped Jumia product listings across multiple product categories.
* Features include product information, pricing details, discounts, ratings, and customer engagement metrics.

## Methodology

* Data Collection using BeautifulSoup
* Data Cleaning & Preprocessing
* Feature Engineering
* Exploratory Data Analysis (EDA)
* Data Visualization
* Categorical Encoding
* Random Forest Regression
* Model Evaluation using MAE and R² Score

## Technologies Used

* Python
* Pandas
* NumPy
* BeautifulSoup
* Matplotlib
* Seaborn
* Scikit-learn

## Key Outcomes

* Analyzed pricing behavior across multiple product categories.
* Identified key factors affecting product pricing, including brand, category, and discount rates.
* Built a Random Forest regression model to predict product prices.
* Generated actionable insights through statistical analysis and visualizations.
